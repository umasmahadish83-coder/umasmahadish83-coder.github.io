# رحلة أبطال التوحيد

موقع تعليمي تفاعلي للأطفال باللغة العربية (RTL) يعلّم مبادئ التوحيد بطريقة مبسطة وممتعة.

محتويات المشروع:
- `index.html` - واجهة ثابتة كاملة تعمل على المتصفح، بها الدروس والألعاب والأنشطة.

ملاحظات للنشر والـ API:
- تم نشر الملفات على الفرع `main` في هذا المستودع. GitHub Pages سيعرض الموقع على:
  `https://umasmahadish83-coder.github.io/`

- الميزة "المعلمة الرقمية" تعتمد على واجهة API خادم عند `POST /api/teacher`. هذه النهاية غير مفعلة في استضافة GitHub Pages لأنها تحتاج خادمًا (server-side).

إذا أردت تشغيل المعلمة الذكية الحقيقية، فإحدى الطرق الآمنة:
1. أنشئ خدمة صغيرة (Node.js/Express أو Functions في Vercel/Netlify) تستقبل POST على `/api/teacher` وتدعو خدمة AI (مثل OpenAI) باستخدام مفتاح مخزّن في متغيرات البيئة.
2. أضف ملف `server/` أو إعدادات Functions وسأجهّز مثالًا جاهزًا لك.

الخصوصية:
- لا يجمع الموقع أي بيانات شخصية من الأطفال. التقدم يُخزن محليًا في `localStorage` فقط.

خطوات مقترحة لاحقة (أستطيع تنفيذها لك إن رغبت):
- إعداد وظيفة سيرفر بسيطة وتوصيل OpenAI أو خدمة مشابهة.
- تمكين HTTPS وتهيئة إعدادات CORS إن لزم.
- إضافة صور/أيقونات ومحتوى مرئياً أكثر وتحسين الوصول (accessibility).
